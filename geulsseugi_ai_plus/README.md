# 글쓰기 AI Plus (Python 없이)

HTML, CSS, JavaScript로 만든 AI 글쓰기 웹앱입니다.

## 기능
- 최대 100,000자 입력
- 핵심 요약 / 글 다듬기 / 새 글 작성
- 글 평가: 총점 및 기준별 점수, 잘한 점, 개선점, 구체적인 수정 예시, 체크리스트
- 피드백 반영 재작성: 평가 결과나 직접 적은 피드백을 바탕으로 글을 다시 작성
- 결과 복사, TXT 저장, 결과를 입력 칸으로 이동
- 모바일 화면 대응
- OpenAI API 키는 서버에서만 사용

## GitHub 없이 배포할 수 있나요?
네. GitHub는 필수가 아닙니다. Replit에서 새 프로젝트를 만든 다음 파일을 직접 업로드하거나, ZIP을 가져올 수 있는 기능이 계정에 보인다면 ZIP을 가져오면 됩니다. Replit의 현재 화면과 요금제에 따라 가져오기 메뉴 이름은 달라질 수 있습니다. 프로젝트에 `index.html`, `api/process.js`, `package.json`, `vercel.json`이 모두 들어가야 합니다.

다른 선택지는 프로젝트 파일을 Vercel에 배포하는 방식이지만, 일반적으로 Git 연동 또는 CLI가 필요합니다. GitHub를 전혀 쓰고 싶지 않다면 Replit에서 직접 프로젝트를 여는 경로부터 시도하는 편이 간단합니다.

## Replit에서 설정
1. Replit에서 새 Node.js 웹 프로젝트를 만듭니다.
2. 이 ZIP 안의 파일을 프로젝트 파일 목록에 업로드/복사합니다. 폴더 구조는 그대로 유지합니다.
3. Secrets / Environment Variables 메뉴에 `OPENAI_API_KEY`를 추가하고 값에 본인의 API 키를 넣습니다.
4. 터미널에서 `npm install`을 실행합니다.
5. Replit에서 Vercel CLI를 실행하는 방식은 Replit 환경에 따라 다를 수 있습니다. 이 프로젝트의 `/api/process.js`는 Vercel 서버리스 함수 형식이므로, Replit에 직접 배포할 경우 Express 서버 형태로 API 경로를 맞춰야 할 수 있습니다. 쉬운 경로는 Vercel에서 배포하는 것이며, Replit에서만 운영하고 싶다면 API 서버를 Replit용으로 바꿔야 합니다.

## Vercel 배포
1. 프로젝트를 Vercel에 배포합니다.
2. Project Settings → Environment Variables에 `OPENAI_API_KEY`를 추가합니다.
3. 저장 후 재배포합니다.
4. 선택 사항으로 `OPENAI_MODEL` 환경 변수를 설정할 수 있습니다. 기본 모델은 `gpt-4.1-mini`입니다.

## 중요
- API 키를 `index.html`, 공개 저장소, 메시지나 스크린샷에 넣지 마세요.
- AI API 사용에는 별도 비용이 발생할 수 있습니다.
- 100,000자는 입력 제한입니다. 긴 글은 여러 번 모델을 호출하므로 비용과 처리 시간이 증가할 수 있습니다.
- 실제 처리 가능성은 선택한 모델의 한도, 계정 사용량, 서버 실행 시간 제한에 따라 달라집니다.
- 글 평가 점수는 참고용이며 학교나 기관의 공식 평가를 대체하지 않습니다.
- 공개 서비스로 만들기 전 인증, 요청 횟수 제한, 비용 상한, 개인정보 안내를 추가하는 것을 권장합니다.
